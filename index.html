Saran Saat Koneksi Lemah atau Data Seluler

  • 1Pastikan tablet di kamar bayi terhubung ke Wi-Fi rumah yang stabil dan cukup dekat dengan router.
  • 2Turunkan kualitas video ke Sedang atau Rendah saat memantau di luar rumah dengan data seluler.
  • 3Biarkan tablet tetap terpasang ke charger dan halaman Mode Kamera tetap terbuka di layar.
  • 4Operator 4G/5G di Indonesia sering menggunakan CGNAT/Symmetric NAT. Jika koneksi 4G gagal (ICE failed), tambahkan server TURN relay gratis (Metered.ca / Cloudflare) di Pengaturan.

Konfirmasi

Panduan Setup Gratis (Firebase RTDB + TURN)

1. Buat Firebase Realtime Database (Gratis / Spark Plan):
Buka console.firebase.google.com → buat proyek baru → menu Build → Realtime Database → Create Database (pilih lokasi Singapore / asia-southeast1) → salin URL database dan tempel di kolom Pengaturan pada Tablet dan HP.

2. Tempel Aturan Keamanan (Tab Rules):

{
  "rules": {
    "arsa_pairing": {
      "$code": { ".read": true, ".write": true }
    },
    "arsa_sessions": {
      "$roomId": { ".read": true, ".write": true }
    }
  }
}

3. TURN Relay untuk Data Seluler 4G/5G (Opsional):
Jika pemantauan keluar rumah memakai data seluler gagal menembus NAT operator, daftar gratis di Metered.ca Open Relay (50 GB/bulan gratis) atau Cloudflare Calls TURN, lalu isi URL, Username, dan Kata Sandi TURN di Pengaturan pada kedua perangkat.
